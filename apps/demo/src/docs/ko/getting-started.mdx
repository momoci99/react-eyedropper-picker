# 시작하기

## 설치

```bash
npm install react-eyedropper-picker
```

React 19.2 이상이 필요합니다. 다른 의존성은 없습니다.

## 컬러 피커 넣기

`ColorPicker`는 input처럼 씁니다. `value`와 `onChange`를 넘기거나 `defaultValue`만 넘기세요. 색은 hex 문자열(`#rrggbb`)입니다.

<Example code={basicPickerCode}>
  <BasicPicker />
</Example>

Chrome, Edge, Opera에서는 입력창 옆에 스포이드 버튼이 생깁니다. 화면 어디서든 색을 뽑습니다. 다른 브라우저에는 EyeDropper API가 없어서 버튼이 숨겨집니다.

## 이미지에서 색 뽑기

`react-eyedropper-picker/loupe`의 `ImageColorPicker`는 확대경이 달린 `<img>`입니다. 모든 브라우저에서 동작하고 터치 화면에서도 됩니다. 누른 채로 끌고, 손을 떼면 색을 뽑습니다.

<Example code={imagePickerCode}>
  <ImagePicker />
</Example>

다른 출처의 이미지는 CORS가 필요합니다(`crossOrigin="anonymous"`와 서버의 응답 헤더). 그렇지 않으면 브라우저가 확대경이 픽셀을 읽지 못하게 막습니다.
