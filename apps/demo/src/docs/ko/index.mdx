# react-eyedropper-picker

색을 뽑는 맛이 있는 React 컬러 피커입니다. 브라우저에 스포이드가 있으면 그걸 쓰고, 이미지라면 모바일을 포함한 모든 브라우저에서 픽셀 단위로 정확한 확대경을 띄웁니다.

<Example code={imagePickerCode}>
  <ImagePicker />
</Example>

이미지 위로 움직여 보세요. 확대경이 픽셀을 하나씩 보여 주고, 휠로 확대하고, 클릭하면 색을 뽑습니다. 이 예제는 소리가 켜져 있어서, 한 번 클릭한 뒤부터는 픽셀을 넘을 때마다 틱 소리가 납니다.

## 들어 있는 것

- **`ColorPicker`**: 채도 패널, 색상·투명도 슬라이더, hex 입력창, 최근 색, 라이트·다크 테마. 키보드와 터치로 쓰기 편합니다.
- **순정 스포이드**: Chromium 계열 브라우저에서는 [EyeDropper API](https://developer.mozilla.org/en-US/docs/Web/API/EyeDropper_API)로 화면 어디서든 색을 뽑습니다.
- **확대경** (`react-eyedropper-picker/loupe`): 모든 브라우저에서 `<img>`, `<canvas>`, `<video>`의 색을 뽑습니다. 자유 배율, 그리드, 샘플링, 터치를 지원합니다.
- **손맛**: 틱·딸깍 소리, 햅틱, 부드러운 추적, 애니메이션을 켤 수 있습니다. 모션 감소 설정을 따릅니다.
- **작고 안전함**: 런타임 의존성이 없고, 타입이 갖춰져 있고, SSR에서 안전합니다. 확대경은 별도 진입점이라 피커만 쓰면 번들이 작게 유지됩니다.
