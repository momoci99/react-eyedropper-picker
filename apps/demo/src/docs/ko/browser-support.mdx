# 브라우저 지원

## 요구 사항

- React 19.2 이상.
- `react-eyedropper-picker/loupe`는 `react-dom`도 필요합니다(`renderLabel` 때문). 기본 진입점은 필요 없습니다.
- 서버 렌더링에서 안전합니다. 브라우저가 컴포넌트를 실행하기 전에는 `window`, `document`, 오디오를 건드리지 않습니다.

## 기능

| 기능 | Chrome, Edge, Opera | Firefox | Safari | iOS Safari | Android Chrome |
| --- | --- | --- | --- | --- | --- |
| `ColorPicker`와 부품 | 예 | 예 | 예 | 예 | 예 |
| 순정 스포이드 (화면 전체) | 예, 데스크톱 | 아니요 | 아니요 | 아니요 | 아니요 |
| 확대경 (`/loupe`) | 예 | 예 | 예 | 예 | 예 |
| 터치: 끌기, 떼기, 두 손가락 확대 | 터치 화면 | 터치 화면 | 터치 화면 | 예 | 예 |
| `theme="auto"` | 123+ | 120+ | 17.5+ | 17.5+ | 123+ |
| 소리 | 예 | 예 | 예 | 예 | 예 |
| 진동 | 아니요 | 아니요 | 아니요 | 아니요 | 예 |

- 순정 스포이드가 없는 곳에서는 스포이드 버튼이 숨겨집니다. 확대경을 `eyeDropper`로 넘기면 어디서나 보입니다. [확대경](/ko/loupe/#colorpicker와-함께)을 참고하세요.
- 소리는 사용자가 페이지와 처음 상호작용한 뒤부터 납니다(브라우저 규칙).
- `theme="auto"`는 CSS `light-dark()`를 씁니다. 오래된 브라우저에서는 `'light'`나 `'dark'`를 쓰세요.

## 테스트 방법

- 단위 테스트는 변경마다 jsdom에서 돕니다.
- 브라우저 테스트(Playwright)는 변경마다 CI에서 돕니다. 마우스를 쓰는 Chromium, 터치를 흉내 낸 Chromium, 마우스를 쓰는 WebKit(Safari 엔진)에서 뽑은 색을 실제 이미지 픽셀과 비교합니다.
- 직접 확인: macOS Safari, Android Chrome 진동.

쓰는 브라우저에서 문제가 있나요? [이슈를 열어 주세요](https://github.com/momoci99/react-eyedropper-picker/issues).
