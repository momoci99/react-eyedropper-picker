## useColorPicker

UI 없이 피커의 상태만 다루는 훅입니다. 내부에서 색을 HSV로 들고 있어서, 색이 검정·흰색·회색이 되어도 색상(hue)이 유지됩니다.

```tsx
const picker = useColorPicker({ defaultValue: '#22c55e' })
```

옵션은 `value`, `defaultValue`, `onChange`, `alpha`, `eyeDropper`로 [ColorPicker](/ko/color-picker/#props)와 같습니다.

| 결과 | 타입 | 설명 |
| --- | --- | --- |
| `hex` | `string` | `#rrggbb`, `alpha`를 켜면 `#rrggbbaa`. |
| `hsv` | `{ h, s, v }` | 색상 0–360, 채도와 명도 0–100. |
| `alpha` | `number` | 0(투명)~1(불투명). `alpha`를 끄면 항상 1. |
| `setHex` | `(hex) => boolean` | hex로 색을 정합니다. 올바르지 않으면 false. |
| `setHsv` | `(hsv) => void` | HSV로 색을 정합니다. |
| `setAlpha` | `(alpha) => void` | 투명도를 0–1로 정합니다. `alpha`를 끄면 무시. |
| `pickColor` | `() => Promise<string \| null>` | 스포이드를 열고 뽑은 색을 적용합니다. 새 hex를, 취소하면 null을 돌려줍니다. |
| `canPickColor` | `boolean` | 이 환경에서 스포이드가 동작함. true일 때만 버튼을 보여 주세요. |

`pickFromScreen`, `isEyeDropperSupported`는 `pickColor`, `canPickColor`의 예전 이름입니다. 0.x에서는 계속 동작하고 1.0에서 없어집니다.

## 부품

| 컴포넌트 | Props | 참고 |
| --- | --- | --- |
| `SaturationPanel` | `hsv`, `onChange(hsv)` | 왼쪽→오른쪽 채도, 아래→위 명도. |
| `HueSlider` | `hue`, `onChange(hue)` | 0–360. |
| `AlphaSlider` | `color`, `alpha`, `onChange(alpha)` | 체커보드 위에 `color`를 투명→불투명으로 보여 줍니다. |
| `EyeDropperButton` | `<button>`의 모든 prop | 스포이드 아이콘 버튼. 아이콘만 필요하면 `EyeDropperIcon`. |

슬라이더와 패널은 `touchBubble`(기본 true), `className`, `style`도 받습니다. 마우스, 터치, 펜, 키보드로 조작할 수 있습니다.

## useEyeDropper

순정 [EyeDropper API](https://developer.mozilla.org/en-US/docs/Web/API/EyeDropper_API)만 감싼 훅입니다.

```tsx
import { useEyeDropper } from 'react-eyedropper-picker'

const { open, close, isSupported } = useEyeDropper()
const { sRGBHex } = await open() // 취소하거나 close()를 부르면 AbortError로 실패
```

EyeDropper API가 없는 브라우저에서는 `open()`이 `NotSupportedError`로 실패하므로 먼저 `isSupported`를 확인하세요. `isSupported`는 서버 렌더링과 첫 렌더에서는 false이고, 그 뒤 Chromium 계열 브라우저에서 true가 됩니다. 같은 확인을 일반 함수로 하려면 `isEyeDropperSupported()`를 쓰세요.

## 색 변환 함수

모두 `react-eyedropper-picker`에서 가져옵니다.

- `normalizeHex`, `isValidHex`, `hexToRgb`, `rgbToHex`, `rgbToHsv`, `hsvToRgb`, `hexToHsv`, `hsvToHex`.
- 알파용: `normalizeHexAlpha`(`#rgb`, `#rgba`, `#rrggbb`, `#rrggbbaa` 중 무엇이든 → `#rrggbbaa`), `hexToRgba`, `rgbaToHex`.
- 타입: `RGB`, `RGBA`(`a`는 0–1), `HSV`.

```ts
normalizeHex('#ABC') // '#aabbcc'
hexToRgb('#ff8000') // { r: 255, g: 128, b: 0 }
normalizeHexAlpha('#f008') // '#ff000088'
```
