# 확대경

`react-eyedropper-picker/loupe`는 `<img>`, `<canvas>`, `<video>`에서 색을 뽑는, 픽셀 단위로 정확한 확대경입니다. 터치 화면을 포함한 모든 브라우저에서 동작합니다. 원본의 픽셀을 직접 읽기 때문에, 몇 배로 확대하든 뽑은 색은 이미지가 가진 값 그대로입니다.

별도 진입점이라 기본 진입점만 쓰는 앱의 번들에는 들어가지 않습니다. `react-dom`이 필요합니다(`renderLabel` 때문). 기본 진입점은 필요 없습니다.

쓰는 방법은 두 가지입니다.

- **`ImageColorPicker`**: 언제든 색을 뽑을 수 있는 이미지. 올려서 겨누고, 클릭해서 뽑고, 몇 번이고 반복합니다.
- **`useLoupeEyeDropper`**: 순정 스포이드처럼, 필요할 때 한 번 뽑습니다. `open()`이 Promise를 돌려줍니다.

## ImageColorPicker

<Example code={loupeOptionsCode}>
  <LoupeOptions />
</Example>

| 입력 | 겨누기 | 뽑기 | 확대 |
| --- | --- | --- | --- |
| 마우스 | 올리기 | 클릭 | 휠 (이미지 위에서만) |
| 터치 | 누른 채 끌기 | 떼기 | 이미지 위에서 두 손가락 |
| 키보드 | Tab으로 이미지에 가서 Enter나 Space를 누르면 전체 화면 확대경이 열립니다 (키는 [아래](#조작)) | | |

- `<img>`의 모든 prop과 `onPick`, `onPickError`, `loupe`([옵션](#옵션)과, hex 라벨을 대신하는 `renderLabel(color)`)를 받습니다.
- `onPick`은 `{ sRGBHex, x, y, mode }`를 받습니다. `x`, `y`는 원본 픽셀 좌표입니다.
- `onPickError`는 읽기 오류를 받습니다. 예를 들어 CORS 없는 다른 출처 이미지는 `SecurityError`입니다. 기본값은 `console.error`입니다.
- 이미지 위의 터치는 페이지를 스크롤하지 않습니다. 다른 곳에서는 평소처럼 스크롤됩니다.

## useLoupeEyeDropper

<Example code={loupeButtonCode}>
  <LoupeButton />
</Example>

`open()`은 원본 위에 확대경을 띄워 페이지를 덮고, 색을 뽑으면 `{ sRGBHex, x, y, mode }`로 끝납니다. 취소하면 `AbortError`로 실패합니다.

### 조작

| 입력 | 겨누기 | 뽑기 | 취소 | 확대 |
| --- | --- | --- | --- | --- |
| 마우스 | 움직이기 | 클릭 | 이미지 밖 클릭 | 휠 |
| 터치 | 끌기 (확대경이 손가락 위에 뜸) | 떼기 | 바깥 탭 | 두 손가락 |
| 키보드 | 방향키 1px, Shift 10px | Enter | Escape | `+` / `-`, `0`으로 처음 배율 |

- `mode`: `'auto'`(기본)는 `source`가 있으면 확대경을, 없으면 순정 스포이드를 씁니다. `'native'`와 `'loupe'`는 한쪽으로 고정합니다.
- `source`는 요소나 ref입니다. `open({ source })`로 다른 요소에서 뽑을 수 있고, `open({ signal })`은 `AbortSignal`을 받습니다.
- 닫히면 `open()` 전에 포커스가 있던 곳으로 포커스가 돌아갑니다. `isOpen`인 동안 버튼을 비활성화하지 마세요. 비활성화된 버튼은 포커스를 돌려받지 못합니다.

## ColorPicker와 함께

훅을 `eyeDropper`에 넘기세요. 피커의 스포이드 버튼이 이미지 위에 확대경을 열기 때문에, 순정 스포이드가 있는 브라우저뿐 아니라 모든 브라우저에서 버튼이 보입니다. 뽑은 색은 `history`에도 쌓입니다.

`ColorPicker`는 `{ open, isSupported }`만 필요하므로 기본 진입점에는 여전히 확대경이 번들되지 않습니다. 직접 만든 피커는 `useColorPicker({ eyeDropper })`로 똑같이 할 수 있습니다.

## 옵션

`ImageColorPicker`와 `useLoupeEyeDropper`의 `loupe`:

| 옵션 | 기본값 | 설명 |
| --- | --- | --- |
| `defaultMagnification` | `8` | 처음 배율. |
| `minMagnification` / `maxMagnification` | `1` / `64` | 배율 범위. |
| `magnificationSteps` | – | 이 값들로만 확대합니다. 예: `[2, 4, 8, 16]`. |
| `magnification` + `onMagnificationChange` | – | 제어 모드 배율. |
| `size` | `120` | 확대경 크기(CSS 픽셀). |
| `shape` | `'circle'` | `'circle'` 또는 `'square'`. |
| `grid` | `true` | 픽셀이 충분히 크면 픽셀 사이에 선을 그립니다. |
| `sampleSize` | `1` | `1`, `3`, `5`: N×N 영역의 평균색을 뽑습니다. 노이즈가 많은 사진용. |
| `className` | – | 확대경 요소의 클래스. |
| `smoothing` | `0` | 0~1: 확대경이 포인터를 부드럽게 따라갑니다. 뽑는 픽셀은 항상 포인터 아래 픽셀입니다. |
| `animate` | `true` | 나타날 때 커지고, 닫힐 때 작아지고, 확대가 부드럽게 바뀝니다. 모션 줄이기 설정에서는 꺼집니다. |
| `cursor` | `'none'` | 이미지 위의 CSS 커서. 커서를 보이면 확대경이 포인터 위로 옮겨 갑니다. `eyeDropperCursor`는 바로 쓰는 스포이드 커서입니다. |
| `sound` | `false` | Web Audio로 만든 틱, 딸깍, 휙 소리. `true` 또는 옵션(`volume`, `events`, `minTickInterval`, `play`). |
| `haptics` | `false` | 틱과 뽑기 때 진동(Android Chrome). |

배율은 기본으로 자유롭습니다. 휠 한 칸이나 키 한 번마다 ×1.1씩 바뀌고, 어떤 배율에서도 가운데 픽셀은 정확히 가운데에 있습니다. 모든 옵션은 [플레이그라운드](/playground/)에서 직접 만져 볼 수 있습니다.

## 영상

`source`에 `<video>`를 넘길 수 있습니다. `open()`은 그 순간 보이는 프레임에서 색을 뽑습니다. 뽑거나 취소할 때까지 그 프레임이 영상을 덮어서, 겨누는 화면이 멈춰 있습니다. 재생은 계속됩니다. 멈추고 싶으면 직접 일시정지하세요.

```tsx
const video = useRef<HTMLVideoElement>(null)
const { open } = useLoupeEyeDropper({ source: video })

<video ref={video} src="/clip.mp4" crossOrigin="anonymous" controls />
<button onClick={() => open().then(({ sRGBHex }) => setColor(sRGBHex))}>Pick from video</button>
```

- 영상에 프레임이 생기기 전에는 `open()`이 `InvalidStateError`로 실패합니다. 예를 들어 `preload="none"`이고 아직 재생하지 않은 경우입니다.
- DRM이 걸린 영상은 읽을 수 없습니다.
- `ImageColorPicker`는 이미지 전용입니다.

## 다른 출처 이미지와 레이아웃

- 다른 출처의 이미지와 영상은 CORS가 필요합니다. 요소에 `crossOrigin="anonymous"`를 붙이고 서버가 알맞은 헤더를 보내야 합니다. 그렇지 않으면 브라우저가 픽셀 읽기를 막아서 `SecurityError`가 납니다.
- CSS `object-fit`, `object-position`, 테두리, 패딩을 따릅니다. 그림이 실제로 그려진 곳에서 뽑고, 레터박스 띠에서는 뽑지 않습니다.
