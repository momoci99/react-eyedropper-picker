## Results

```ts
// useEyeDropper().open(), and what EyeDropperLike.open resolves with
type ColorSelectionResult = { sRGBHex: string }

// useLoupeEyeDropper().open()
type PickResult = {
  sRGBHex: string // #rrggbb
  x?: number // source pixel, loupe mode only
  y?: number
  mode: 'native' | 'loupe'
}

// ImageColorPicker onPick, renderLabel
type LoupePickResult = { sRGBHex: string; x: number; y: number; mode: 'loupe' }
```

Errors are `DOMException`s, like the native API: `AbortError` (cancelled), `NotSupportedError` (no eye dropper), `SecurityError` (cross-origin pixels), `InvalidStateError` (a video without a frame yet).
